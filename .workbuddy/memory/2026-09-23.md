## 第六次修订：落剑换成原作的剑（用户反馈驱动）

### 用户诉求

> "现在，我的剑雨是蓝色的剑，并且是简单的图形绘制的，请你修改的和游戏里一样"

上一版回退后，落剑是 `game.cpp` 里用图元硬画的：**白线当刃 + 蓝护手 `{95,174,231}` +
天蓝辉光**。用户明确不认这套，要**和游戏里一样**。注意诉求只针对**外观**，
**落剑雨机制（持续 1.35s、±130px、920 下落、0.12s 间隔、1.55 法术 + 0.42s 晕眩、14s CD）
一个字都不许动**。

### 找素材：为什么最终用 `F_Weapon`

- 剑雨是德克萨斯自己的 **S2**，所以最合理的"原作剑"就是**她本人举的那把剑**。
- 试过 S2 特效包 `TT_texas2.ab.json`：里面有 GameObject 叫 `"jian"`（剑，绑 `texas2_01`），
  但 `texas2_WP_01/02` 两个武器节点挂在 **`"hammer_andi"`** 下 —— 不是这把剑，
  而且那是特效贴图不是武器本体。**弃用**。
- 最终取 **官方客户端 `char_102_texas` 图集**（`.battle-staging/texas_atlas.png`，512×512）
  的 `F_Weapon` 区域 = `(108, 468, 108, 42)`。数值核对颜色：**金色刃 ≈ (240,224,80)、
  深藏青柄 ≈ (32,32,48)** —— 完全没有蓝色，正好对上用户的抱怨点。

### 烘焙（`output/_tmp_new/bake_texas_sword.py`，新增）

- 裁 `F_Weapon` → 只取 `alpha > 40` 的墨迹做**加权 PCA** 求刃主轴：
  `theta = 0.5 * atan2(2*sxy, sxx - syy)` → 实测 **−17.66°**（剑在图里是斜的）。
- `rotate(90.0 + angle, BICUBIC, expand=True)` 把刃转成垂直；
  再 `ImageOps.flip` 让**刃尖朝下**（剑是往下落，不是往上）。
- 裁到 alpha bbox、外扩 2px → 存 `assets/operators/texas_sword.png`。
- 结果 **19×118 px**，墨迹 px = 780，金色刃到下方收成尖端。
- ⚠ 因为本会话**看不到图片**（图像 Read 返回 "model does not support images"），
  整个几何变换只能靠 `alpha getbbox()` + 主轴角度 + 颜色直方图自证，不能靠眼。
