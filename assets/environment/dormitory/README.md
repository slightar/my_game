# 基建 / 宿舍式横版场景

按用户要求，用内置 imagegen 绘制的风格化游戏素材，参考明日方舟基建和宿舍的模块化家具、Q 版适配比例与柔和材质。不是客户端原始资源，也不是程序图形拼绘。

`clinic.png` 医疗室，`street.png` 灰雪街区，`industry.png` 维修室，`burn.png` 受损指挥室，`system.png` 系统机房，`props.png` 透明平台 / 门洞 / 通风口 / 钟楼图集。当前五类主题供 20 个区域复用。最终完整提示词在 `prompts.json`。

原始 PNG 直接复制到项目，保留透明图集 alpha。渲染器按源图区域显示素材，碰撞体只参与逻辑，不绘制到画面。各场景地面取样高度由 `WorldScenery::Art` 记录，统一对齐角色脚底；长区域以固定尺度镜像连接房间模块。

本轮使用内置图像生成工具，未使用 CLI/API 回退。先前的写实稿保留在 `../painted/`，但游戏不加载。
