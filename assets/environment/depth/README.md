# 场景视差层

这些透明 PNG 为内置 image_gen 根据现有场景绘制的独立装饰素材。初版远景及已停用的共用近景提示词见 prompts.json；当前 26 个区域各自使用 <region>_front_v2.png，完整提示词与生成路径见 regions-front-v2-prompts.json。诊疗所用医疗推车、零号病房用床单与护理用品、钟楼用齿轮链条、车站用轨道器材与行李车、避难所用生活物资，六个前置区域也使用自己的调查/作业主题物件。远景仍按室内、街区、系统空间共用；industrial 远景复用 street_back。

WorldDepth 的配置独立于 WorldArt 的门、楼梯和落脚线。绘制顺序为：原背景 → 慢速远景细节 → 敌人/角色 → 快速近景 → UI/旁白 → 转场。原全景中的建筑仍属于主体层，本版新增的是独立远景细节与近景，并非将所有原有建筑逐件拆层。

远景位移倍率 0.62、主体 1.0、近景 1.22；倍率相对于实际镜头位移，因此镜头停在边界时装饰也停下。位置由镜头和固定世界位置决定，不依赖时间，往返与回访保持一致。远景循环绘制；近景不循环、不镜像，每张素材中三个不同物件组沿场景各摆一次。远景纹理按主题缓存，近景按区域缓存，切换时释放旧纹理。

加载近景时，从透明分隔带识别三个物件组的图像范围，再按原始比例分别缩放至不超过 80 高、320 宽，贴于画面底部；不拉伸图片，也不把生成图的空白边距算作物件尺寸。远景图高 540、顶部略出画面。近景不增加碰撞。调整参数见 src/world_depth.h。缺失装饰图或缺少任一物件组时 depth-audit 会失败；原完整背景保留。
