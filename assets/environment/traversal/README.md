# 叙事探索版场景

本目录包含用内置 imagegen 生成的五张连续全景图：street、industry、clinic、burn、system。不是客户端原始资源。完整最终提示词见 prompts.json；后三张以 industry.png 为编辑参考，保留门洞和地面位置。原图直接复制进项目，未用程序绘图或后期拼贴门洞。

新版以全幅场景代替镜像拼接。三处旧门是背景固有的一部分，街道门中心在画面宽度的 12%、28%、43.5%；室内门中心在 9.8%、26.5%、40.5%。WorldLayout::Ports 与这些位置对应。主线从出发点向右延伸，支路在出发点后方，玩家自行回头寻找。

地面统一对齐角色脚底。移除悬浮平台与单独门贴图。靠近不改变画面结构、不保存发现；长按 F 1.15 秒才开始通行，松开或离开即取消。只有实际进入区域且存档成功后，隐藏关卡才出现在原有关卡选择界面。

PRTS 当前为字幕引导，包含前进、回头提醒、旧门劝阻三种反馈。场景间切换为 0.36 秒淡出、黑场加载与标题、0.48 秒淡入，总计约 1.1 秒，期间不接受移动或菜单输入。主线右侧出口自动通行，左侧原路返回需按 F，避免探索时误切换。

20 个区域暂时复用这五类场景；独立关卡美术、战斗和配音尚未制作。旧版美术和完整设计大地图仍保留在项目中。
