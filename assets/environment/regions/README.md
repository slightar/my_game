# 每区域独立场景

20 个区域各自读取同名 PNG，不再按五类主题共用背景。保留诊疗所 clinic 和灰雪街区 gray，使用内置 imagegen 新绘其余 18 张全景。完整最终提示词见 prompts.json；保留图的提示词来源也记录在该文件中。未使用程序图形拼绘、换色复制或镜像重复。

独立环境包括钟楼机械层、高架入口、废弃车站、隔离病房、高架桥、屋顶通讯塔、通讯办公室、维护井、冰封住宅、热能管道、生活避难所、工业检查关口、燃烧商业街、城市核心露台、撤离屋顶、地下数据根系、PRTS 核心和王座。

每张图的地面高度和侧路位置在 src/world_art.h 单独配置，按实际生成画面校准；WorldLayout::Ports 使用同一配置。主路、隐藏发现、PRTS 字幕与淡入淡出沿用叙事探索规则。部分背景物件仅为环境装饰，未新增战斗、解谜或交互家具。

旧版 traversal、dormitory、painted 素材仍保留，但探索场景只加载本目录。全区域实机截图为 output/world-map-qa/world-qa/region-区域ID.png。
