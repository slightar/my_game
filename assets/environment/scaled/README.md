# 场景物件尺度修正

本轮保留原角色尺寸，使用内置 imagegen 编辑 14 张背景中的普通门、病床、椅子、台面等物件。没有通过放大角色补偿背景，也没有缩短区域或缩放整张地图。大桥、工业设施、远景建筑等结构可以维持较大尺度。

最终 PNG 位于本目录，首轮与诊疗所最终提示词见 prompts.json；避难所二次修改见 shelter-refinement.txt。输入为 ../regions 下的同名图，clinic 和 shelter 最终稿又以第一轮缩小稿进行第二次修正。原始素材保留。

代码通过 WorldArt::Repainted 明确选择素材，PaintedGround 单独校准绘制地面，不改变先前的地图宽度。病房与核心入口中心已按新稿重新对准。提示文字移到上方，避免遮挡角色及床边对照。

审查应以游戏内原尺寸角色与门边、床边同屏为准，不能仅凭背景原画或生成提示词认定比例正确。当前物件仍为背景图像，未实现坐卧交互。
