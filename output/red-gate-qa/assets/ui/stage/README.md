# 客户端关卡素材

来源：用户指定的 `C:/Program Files/Arknights bilibili/games/Arknights/Arknights_Data/StreamingAssets/AB/Windows`。
`sources.json` 逐项记录原始资源包、Sprite 名称及尺寸。PNG 为 Unity Sprite 无损导出，未修改安装目录。

- `bkg_*`、路线标识、通关标识：客户端关卡节点素材，按原比例显示。
- `main_*`、`scene_main_*`：原章节图片，用作界面展示素材；本项目任务和剧情标题另行显示。
- `sprite_background`、`btn_close`、`confirm_icon`、`btn_shadow`：原通用界面素材。
