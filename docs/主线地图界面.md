# 主线地图界面

主页选择“终端”，进入横向行动路线图。章节栏定位区域，按住鼠标左键拖动、滚轮或底部箭头横向浏览，左右键选择已发现节点。拖拽超过 6 个逻辑像素后，释放不会触发节点选择。
主线节点同一水平线从左向右排列；隐藏区域从剧情数据中的关联区域分出，未解锁节点和相关连线不会提前显示。

点击节点仅更新右侧行动简报，不保存起点、不完成节点。简报显示地点、任务、关联角色及奖励。
点击“开始行动”保存起点并留在当前地图；右侧显示“起点已就绪 · 地图场景尚未实现”。不会再自动打开旧版开发占位页。Esc 先关闭简报，再返回主页。
原有节点完成与双结局占位仍保留在 F9 开发入口，用于验证进度数据。
页面的选择只决定进入连续世界的起点。TODO：真实地图场景、区域接缝、移动与地图流式加载尚未实现。

## 本次文件

- `src/action_map.h/.cpp`：布局坐标、横向浏览、节点连线、右侧简报及确认入口。
- `src/main_menu.h/.cpp`、`src/menu_views.cpp`：页面接入，移除旧网格地图绘制。
- `src/ui_assets.h`、`assets/ui/stage/*.png`：从用户指定客户端无损导出的节点、章节、通用面板纹理；来源见该目录 `sources.json` 和 `README.md`。不覆盖旧资源。
- `src/ui_input.h`、`src/game.h/.cpp`、`src/terminal_ui.h/.cpp`：记录按下来源，松开确认，拖出取消；小按钮内边距修正。
- `src/progress_glyphs.h`：补充中文字符。
- `CMakeLists.txt`、`tests/ui_interaction_tests.cpp`、`tests/menu_render_checks.h`：输入回归、布局覆盖及图形交互检查。
