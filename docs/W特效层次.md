# W 特效层次

- 枪口：客户端原 `cqbw_attack_01_start` 的枪口火光、亮闪、暗底、速度线和火星；`start_02` 的烟尘在角色后方消散。
- 飞行：原 `cqbw_attack_01_trail_01` 的两层烟和速度线，沿实际榴弹轨迹回溯最多 0.336 秒。烟尾长度受弹龄限制，暂停时不继续动画。
- 普通爆炸：闪光、原 16 帧翻卷爆焰、40 帧火焰与黑烟、冲击环、弧线散射碎片。火焰恢复透明混合，保留烟的颜色和体积。尾烟与地面焦痕位于角色及预警后方；空中命中不画地面焦痕。
- C4：更饱满的火焰，原骷髅闪光，0.5 秒后的原短电光，以及最长 3 秒的缓升余烬、4 秒烟尘。倒计时与锁定提示保持在烟层前方。
- 烟尘与余烬不产生额外伤害。伤害半径、起手、追踪锁定、0.35 秒爆炸判定、榴弹飞行命中和拦截逻辑保持原设定。
- 地雷本体使用原 W 地雷模型的完整 Idle 姿态 `w_mine.png`，以 `(64,120)/128` 的脚底锚点贴地显示。`cqbw_04` 是碎片层展开图，不用于地雷本体。灯光对齐原模型红色天线。

资源：`assets/enemies/bosses/effects/w_client/`。使用本地客户端原图与采样曲线，对横版位置、大小、亮度和粒子轨迹进行适配，并非完整 Unity 特效逐帧复刻。

验证：`world_map_smoke --w-fx-audit` 在隔离测试目录中运行，捕获枪口、飞行、普通爆炸的多个阶段及 C4 的预警、爆炸和消散。伤害回归使用 `w_combat_tests` 和现有测试集。
