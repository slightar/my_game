# 十一类小怪：动作游戏第一版

## 体验入口

主页点击「小怪试炼 / N」，或按 N；向右走出安全室，进入十一只敌人的试炼阵型。
原有 B 弑君者演示仍可独立进入。角色、改键、暂停与返回主页沿用原系统。
此试炼不修改剧情进度。默认 J 攻击、W/空格跳跃、S/Shift 闪避、Q/E 技能、1/2 切换。
清场或失败后 Enter 重试，Backspace 返回；Esc 暂停。

## 行为与数值

下表为本项目动作玩法调参，并非原作塔防数值。攻击命中沿用角色现有的扣 1 生命、无敌帧和击退。

| 类型 | 生命 | 移速 px/s | 前摇 s | 设计与应对 |
|---|---:|---:|---:|---|
| 源石虫 | 6 | 100 | 0.40 | 低矮近战：短前摇扑咬，跳跃或闪避后反击 |
| 酸液源石虫 | 11 | 84 | 0.95 | 远程腐蚀：400 像素内吐酸液（弹速 290，比弩箭慢），命中后削弱防护，见下节 |
| 高能源石虫 | 15 | 104 | 0.95 | 结晶腹部：耐打的行走炸弹，死亡**必定**物理引爆（1.00 秒引信），务必在远处解决 |
| 辐能源石虫 | 18 | 74 | 0.60 | 法术引爆：死亡时泄漏能量，为场上其他敌人「供能」加速，见下节 |
| 士兵 | 12 | 100 | 0.62 | 接近后锁定朝向斩击，留下 0.85 秒后摇 |
| 弩手 | 9 | 72 | 0.90 | 保持 200–440 像素距离；红线锁定位置后发射直线弩箭，靠近会后退，墙角可射击；剑气可抵消弩箭 |
| 术师 | 8 | 66 | 1.05 | 远程法术：弹速 290 慢于弩箭 410，但**无视大盾兵的物理减伤**；只有 8 血 66 移速，贴身就是唯一解 |
| 猎狗 | 8 | 168 | 0.34 | 全场最快，但身板脆；扑咬前摇极短，看到起手就得拉开或抢先击退，硬拼换血不划算 |
| 隐形弩手 | 10 | 78 | 0.85 | 默认隐身，见下节；靠 220 像素内接近显形，用近战解决 |
| 重装防御者 | 36 | 46 | 0.95 | 正面物理减伤 80%；背后/法术全额伤害；盾击后摇 1.25 秒。走上前后瞬间转向（无转身演出），开战 0.4 秒内背后也不吃额外伤害 |
| 妖怪 | 16 | 70 | 1.10 | 悬浮在离地 260 像素处巡航；锁定后发射能量弹（射程 520，最远），侧移或打断瞄准线 |

所有近战有前摇提示；弩手、术师、隐形弩手、妖怪、酸液源石虫有瞄准线，引爆系源石虫有倒计时和危险圆，重装防御者受击显示格挡。
爆炸结束、残余弩箭消失后才判清场，避免最后一只引爆系源石虫死亡时提前结算。
试炼模式启用枪械低位辅助瞄准，使能天使能击中源石虫；原有 Boss 模式维持原弹道。
玩家近战每挥击能命中多只小怪，但同一挥击不会逐帧重复伤害同一目标。
投射物采用路径碰撞并优先命中最近目标，降低高速子弹穿透漏判。

## 酸液源石虫：腐蚀

角色没有防御力属性，所以原作「防御力下降」在这里改写成**受击后无敌帧减半**
（1.0 秒 → 0.5 秒），连续挨打的频率翻倍，是唯一能加速掉血的 debuff。

- 酸液弹速 290、绿色团块（`EnemyBolt::corrosive`），命中后 `corrosionTimer_ = 5 秒`。
- 命中回调走 `EnemySystem::AttackHits(..., bool* corrosive)` 的输出参数，
  由 `Game` 转交给 `Player::TakeDamage(Vector2, bool corrosive)`——腐蚀标记因此不污染
  通用的命中判定，近战/远程共用一条路径。
- **必须看得见**：`Player::IsCorroded()` 驱动左上角右侧一枚
  「腐蚀 // CORRODED」徽章（剩余秒数 + 进度条）。没有这枚徽章玩家只会觉得
  「怎么突然连着挨打」，无从归因。
- 解法是脱离酸液 5 秒自然清除；酸液源石虫自身 11 血 84 移速，且属于 `KeepsDistance`，
  被贴到 200 像素内会后退，优先点掉最省事。
- 数值位置：`player.cpp` 的 `kCorrosionDuration` / `kCorrodedInvincibilityScale`。

## 辐能源石虫：引爆与供能

两只引爆系源石虫共用 `DetonatesOnDeath = 高能源石虫 || 辐能源石虫`，被击杀时进入
`Fuse` 蓄爆而不是直接死亡（也因此保留「死了也可能带走你」的压力）：

| | 引信 | 爆炸读色 | 附加效果 |
|---|---:|---|---|
| 高能源石虫 | 1.00 s | 红圈（物理） | 无 |
| 辐能源石虫 | 1.10 s | 紫圈（法术） | 死亡瞬间给**其他所有存活敌人**挂 3.5 秒供能 |

供能期间目标移速 ×1.5。这是原作「死亡后…使场上敌人获得 1 点能量」的动作化改写：
原作里是抽象的能量，这里读作**一次全场提速的连锁威胁**，所以杀它的时机很讲究——
先清杂兵再点它，而不是反过来给自己加难度。

- 数值位置：`EnemySystem::kEnergizeDuration`（3.5 s）、`kEnergizeSpeedScale`（1.5）。
- 渲染：紫色「供能」标签 + 紫圈（`enemy_renderer.cpp`）。没有这圈提示，提速只会
  读成「怪物走路突然变怪」。

## 隐身弩手：只看几何的隐身

隐身不是「无敌」，而是一条纯粹的**距离规则**，判定集中在 `EnemySystem::Tick` 与
`ResolveBullet`：

- 每帧重算 `cloaked = !射击中 && 距离 > kCloakRevealRange`，其中射击中 = `Windup` 或
  `Strike`；`kCloakRevealRange = 220` 像素，公开在 `enemy_system.h` 供测试和渲染复用。
- **远程子弹直接穿过**：`ResolveBullet` 里 `if (!melee && !u.InterceptsProjectiles()) continue;`，
  子弹不消耗、不减速、生命期照常，所以隐身单位对远程玩家等于不存在。
- **近战完全不受影响**：过滤条件只看 `!melee`，玩家的近战挥击照常结算伤害和击退。
- **靠近即显形**：走进 220 像素立刻可见；退开又恢复隐身（没有一次性开关）。
- **前摇期间强制显形**：`Windup`/`Strike` 会解除隐身，所以它的瞄准线和 ! 提示永远可读，
  不存在「看不见就挨打」的情况。玩家选择就是「要么走进去打，要么绕开」。

渲染上隐身读作**半透明剪影**（`Fade(Color{150,168,190,255}, .20F)`）而不是全透明，
另画一圈淡色虚线圈和「隐身」标签——否则会被当成渲染故障而不是机制。

## 体型比例：从烘焙产物推导，不靠手感

`enemy_data.cpp` 里的 `height` / `spriteSize` 是算出来的。烘焙器统一按
`scale = min(174/unionW, 164/unionH)`（spine 单位 → 像素）出图，所以某模型的真实尺寸是
`(表中墨迹高度) / scale`，而这些 spine 单位在所有模型间通用。把士兵（普通人类，367 单位）
锚定到 110px（玩家立绘 112px）就固定了 `C = 0.29976 px/单位`：`height = C × 单位高度`、
`spriteSize = C × 192 / scale`。

推导结果（`output/_tmp_new/size_table.py`，已与 `enemy_data.cpp` 逐项核对一致）：

| 类型 | 单位高度 | height | spriteSize |
|---|---:|---:|---:|
| 重装防御者 | 392.2 | 118 | 138 |
| 隐形弩手 | 377.0 | 113 | 184 |
| 士兵 | 367.0 | 110 | 196 |
| 弩手 | 359.4 | 108 | 183 |
| 术师 | 347.8 | 104 | 139 |
| 猎狗 | 256.6 | 77 | 109 |
| 辐能源石虫 | 242.6 | 73 | 140 |
| 酸液源石虫 | 233.7 | 70 | 114 |
| 高能源石虫 | 213.1 | 64 | 170 |
| 妖怪 | 212.8 | 64 | 175 |
| 源石虫 | 187.7 | 56 | 95 |

上一版的问题正是 `spriteSize` 靠手填：猎狗被画成术师的一半大，尽管两个模型的真实尺寸接近。

两点容易踩：

- `spriteSize` 是**贴图方框边长**，不是可见高度——方框有透明留白，可见高度是 `height`。
- `width` **不在这张表内**，它是手调的**受击盒**宽度。模型包围盒含张开的手臂和武器
  （士兵实测 398px 宽），照搬会让脚下阴影和格挡线宽得离谱，因此收紧到躯干；
  只有 `reach` / 阴影椭圆 / 格挡线读它，与精灵绘制无关。

`tests/enemy_tests.cpp` 里有对应的比例回归断言（源石虫 < 猎狗 < 士兵、
士兵与术师同量级、重装防御者不小于士兵），防止以后再次手填走偏。

## 模块

- src/enemy_data.h/.cpp：十一种敌人定义和参数（`height`/`spriteSize` 由烘焙产物推导）。
- src/enemy_system.h/.cpp：状态机、命中、护盾、蓄爆/引爆、供能、弩箭与酸液、隐身显形、试炼阵型。
- src/enemy_renderer.h/.cpp：精灵表与前摇/血条/格挡/隐身/供能显示。
- assets/enemies/mobs：十一类精灵表、锚点、来源与踩坑说明；妖怪采用本地模型，重装防御者新版保留各动作原始朝向和时长。
- src/game.h/.cpp：独立试炼、角色目标选择、子弹和受击衔接（腐蚀标记输出参数）。
- src/player.h/.cpp、src/game_types.h：腐蚀 debuff 与对应 HUD 徽章、可选辅助瞄准及多目标近战命中记录。
- src/main_menu.h/.cpp、src/menu_views.cpp、src/terminal_ui.h、src/progress_glyphs.h：入口和字形。
- CMakeLists.txt、tests/enemy_tests.cpp、tests/enemy_render_checks.h、tests/game_enemy_smoke.cpp、tests/character_render_smoke.cpp：构建、行为测试与渲染检查。
- tools/extract_enemy_models.py、tools/enemy_model_catalogue.py、tools/bake_enemy_sheets.py/.html：只读提取、模型清单和离线烘焙。

character_render_smoke 导出 enemy-roster.png（十一张卡，2 行 × 6 列）、enemy-directions.png、
enemy-telegraphs.png（高能源石虫蓄爆 / 弩手瞄准 / 酸液瞄准）、
enemy-stealth.png（同屏对比隐身/显形，并附带供能演示）、corroded-hud.png（腐蚀徽章）。
game_enemy_smoke 在独立拷贝目录中运行，检查试炼入口、低位枪击、角色切换、暂停和返回原 Boss 演示，并导出实战截图。

**注意**：渲染检查需要 exe 同级的 `assets/`。用 `output/_tmp_new/build.py` 直接产出的 exe
不会自动拷贝资源，新增精灵表后要手动同步到 `cmake-build-debug/assets/enemies/mobs/`
（`output/_tmp_new/sync_mobs.py`），否则 `HasSprite` 断言会以「Missing enemy sprite sheet」失败
（症状是四个新怪全部退回占位方块）。
