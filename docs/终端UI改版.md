# 终端 UI 改版

依据本地 `arknights-ui` 技能，以现有主页右侧的黑白功能块为参考。沿用 raylib、现有角色立绘、地图素材与实际菜单逻辑。

## 页面与视觉

- 主页右侧保持原构图和强调色。
- 编队：左侧干员列表、中部立绘档案、右侧出战配置与参数。
- 档案：分类导航、记录目录、白色档案正文。
- 装备：顶部装备栏、持有物品列表、白色效果详情。
- 设置：左侧栏目说明、右侧设置条目；键位列表和重置确认同步使用终端样式。
- 角色工坊：白色表单与深色动作预览区；保留生成、原图、模板和保存操作。
- 地图：统一栏目页签、节点简报、区域详情和行动入口。
- 战斗与开发者房间：白色身份栏、深色状态区；暂停菜单使用黑白大区块与蓝色选中条。

公共颜色、表面、标题和按钮位于 `src/terminal_ui.*`。编队列表和设置条目的绘制、点击区域共用几何定义，避免视觉位置与点击位置不同步。

## 验证

- 完整 CMake 构建通过，更新 `cmake-build-debug/my_game.exe`。
- `character_render_smoke`：菜单绘制、编队保存、音量滑块、设置子页、地图选择与拖动、装备确认和结局流程通过。
- `character_creator_smoke`：空态、预览、动作选择、错误提示与本地保存通过；不发送收费的生成请求。
- `world_map_smoke --ui-audit`：开发者房间、战斗 HUD、暂停、点击继续和点击返回主页通过。
- 菜单实际 GPU 截图检查覆盖 1280×720，以及编队的 1920×1080 / 960×540、设置的 960×540 和城区地图的 1920×1080。
- CTest 16/17 通过；`prts_narrator_tests` 未能启动，系统返回 `operation not permitted`，因此该项没有测试结果。

截图位于 `cmake-build-debug/character-qa/`；战斗截图位于 `cmake-build-debug/ui-audit-runtime/world-qa/`。

`world_map_smoke` 会创建和重置其可执行文件所在目录的测试存档。此次在独立的 `ui-audit-runtime` 目录运行，仅共享只读素材，未用玩家存档进行测试。

本项目是 Windows 原生游戏，继续使用既有 1280×720 逻辑画布和等比缩放；此次验证的是桌面窗口大小，不包含手机布局。
