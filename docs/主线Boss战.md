# 主线 Boss 战

2026-10-13 追加的八种角色技能、特效与测试见 [Boss 技能扩展](Boss技能扩展.md)。

在现有关卡界面点击行动，仍先进入对应过渡区域清理小怪；向右穿过过渡区域后，进入高架桥（弑君者）、通讯塔上层（W）、冰封居住区（霜星）或工业区关口（爱国者）。行至场景宽度的 36% 触发遭遇，出现血条和 PRTS 提示。战斗期间玩家可在整张场景中移动，出口仍需击败 Boss 才开放。

本次行动内再次返回已击败的 Boss 区域不会重新生成敌人。重新开始行动或全队败北后按 Enter 重试，会重新生成 Boss；重试直接从当前 Boss 区域入口开始。击杀记录属于当次行动，不写入长期存档。

霜星与爱国者使用倒地重生的两条生命，专场、技能、原客户端特效与音乐详见 [霜星与爱国者](霜星与爱国者.md)。第一条生命耗尽不会解除封锁。

## 攻击与技能

| Boss | 区域 | 当前横版战斗效果 |
| --- | --- | --- |
| 弑君者 | 高架桥 `bridge` | 直接复用主页 B 键的自制 Boss：近身斩击；远距离循环冲刺、空中斩击、三枚飞刀；半血后加快节奏并在冲刺前闪现到玩家背后。基础生命 60。 |
| W | 通讯塔上层 `wtower` | 走位投弹、榴弹连射、感应地雷、后跳/跃过玩家换位反击、C4。半血后连射最多五发、地雷布设三枚、C4 三个落点。生命基准 110。 |

射击、近战及技能使用现有攻击判定；切换干员继续使用场景两端的正常边界。W 的眩晕上限为 0.8 秒；弑君者沿用 B 键版本的眩晕计时；打断 W 的 C4 施放会让已生成的炸药立即爆炸。击败 Boss 后取消尚未结算的爆炸和榴弹，播放对应资源中的败退／死亡动作，再恢复出口。

这些距离、生命及冷却是本项目的横版适配参数。弑君者使用用户自制的 B 键版本，不再使用旧版接近后闪现的简化逻辑；原作 W 的 C4 选择干员目标，本项目只有一个当前操控角色，因此用锁定后可躲避的地面位置表示一枚/三枚炸药。

主线已启用 [自适应难度](自适应难度.md)：表内生命、移动速度、后摇、弹速及后续技能冷却作为原始基准，由上一场战斗表现生成本场倍率；攻击前摇、闪现动画及 C4 倒计时保持原值。倍率在进入区域时冻结，当前战斗内不更新。弑君者只应用生命倍率，招式速度与时序保持 B 键版本。

## W 的机动与组合招式

W 在普通决策、攻击后摇和连射期间持续走位，移动速度基准 185，围绕与玩家 340～500 的距离来回换位置。攻击前摇和 C4 施放阶段留出稳定的反击窗口。

| 招式 | 预警与效果 |
| --- | --- |
| 单枚榴弹 | 0.85 秒前摇锁定落点，沿弧线飞行；途中碰到玩家造成 1 点伤害并在碰撞处爆炸，该枚榴弹随即消失。未碰到玩家时落地范围爆炸；剑气可击毁。 |
| 榴弹连射 | 0.85 秒前摇一次展示全部落点，随后每隔 0.24 秒发射一枚；满血三发，半血后最多五发，落点间距 125。靠边时合并重复落点。施放中边移动边发射。 |
| 感应地雷 | 0.70 秒布设预警，满血两枚、半血三枚。落地后 0.8 秒激活，玩家贴近会触发额外 0.8 秒引爆倒计时。跳得足够高时不会触发；已触发的地雷可通过离开爆炸范围躲避。最多保留四枚，12 秒自动清理。 |
| 后跳/换边 | 玩家贴近、持续命中，或半血阶段需要主动换位时触发。0.25 秒换位方向预告，再以 0.72 秒弧线跳跃移动；靠墙时选择玩家另一侧。留下一枚感应雷，落地接有预警的榴弹连射。通常冷却 5.5 秒、半血 4.3 秒，并接入自适应冷却倍率。跳跃仍可受伤，眩晕会打断位移并使其落地。 |
| C4 | 保留 3.2 秒倒计时：前 1.7 秒跟随玩家，随后锁定最终落点。半血时重置技能冷却并增加至三枚；若正在跳跃，落地后优先响应已就绪的 C4。打断施放立即引爆已装炸药。 |

持续命中产生的压力值每秒衰减 2，每次受伤最多增加 4，达到 6 后可以触发一次换位。换位有独立冷却，避免每发子弹都迫使 W 跳跃。目的地控制在玩家附近的可见交战范围，清理已击败 Boss 时会同时移除所有地雷。

半血变化仅强化随后开始的招式：已经预告的连射落点和地雷落点保持不变。连续榴弹、感应地雷和换位反击是本项目新增的横版招式，沿用敌方 W 的客户端 `Move / Attack / Skill` 动作；跳跃通过角色世界位置的弧线移动表现，原始贴图比例保持一致。

## 客户端模型

客户端来源包：`refs/arts/enm_art_base_0.ab`。

- 弑君者：主线高架桥现使用项目原有的 `assets/enemies/crownslayer_battle.png`，与主界面按 B 进入的战斗保持同一套 `Idle / Move / Attack / Disappear / Appear / Die` 动画。客户端 `enemy_1502_crowns` 图集保留在资源目录供对照。
- 敌方 W：`enemy_1504_cqbw`，使用 `Idle / Move / Attack / Skill / Die`。

W 的每个动作烘焙为 20 帧，使用同一脚底锚点及缩放比例；逐帧纹理及资源指纹位于 `assets/enemies/bosses/`。弑君者使用原项目 10×6 帧图集，并与 B 键共用动画播放、飞刀绘制及全部招式；旧版附加残影与客户端斩击特效不再用于该角色。W 的榴弹、地雷和 C4 使用客户端 `cqbw.ab` 纹理。原 Unity 粒子系统没有在当前引擎中直接运行。

PRTS 公开资料：[弑君者（敌方）](https://prts.wiki/w/%E5%BC%91%E5%90%9B%E8%80%85%28%E6%95%8C%E6%96%B9%29)、[W（敌方）](https://prts.wiki/w/W%28%E6%95%8C%E6%96%B9%29)。

## 模块与验证

- `story_boss.*`：战斗状态、技能、弹道、伤害及当次行动击杀记录；无贴图、输入及音频依赖。
- `story_boss_renderer.*`：弑君者原项目动画、其他 Boss 的客户端模型动画、落点预警、Boss 血条。
- `world_preview.cpp`：区域触发、干员攻击接入、整张场景移动、出口解锁和 PRTS 事件。
- `story_boss_tests`：触发、无敌阶段、斩击、闪现、快速子弹碰撞、榴弹、C4 跟随/锁定/爆炸、半血、打断、击杀与原模型元数据。
- `world_map_smoke --story-boss-audit`：真实游戏更新路径下的攻击、切换干员、封锁、半血 C4、击败后前进/返回、全队败北与重试；输出战斗截图。
- `w_combat_tests`：持续走位、连续榴弹、地雷延迟与实际伤害、后跳、墙边换向、受击换位冷却、跳跃中眩晕、半血预警冻结及击杀清理。
- `world_map_smoke --w-mobility-audit`：通过游戏更新流程观察所有新招式和原始动作、验证玩家受到地面爆破伤害、半血连射及清理；长期观察部分使用保持存活的测试角色。

复现美术资源时，先运行 `extract_chapter_enemies.py --bosses` 提取，再通过 `bake_enemy_sheets.py --page tools/bake_story_bosses.html` 烘焙，最后运行 `install_story_bosses.py` 安装。提取及烘焙输入输出均放在忽略的 `output/story-bosses/` 中。

自制弑君者的共享战斗逻辑位于 `src/boss.cpp`，共享动画、飞刀与赤影处刑演出位于 `src/boss_renderer.cpp`。主线与开发者房间通过 `StoryBoss` 接入相同控制器，按场地调整边界并传入玩家朝向。

## 招式变化（2026-10-04）

以下为基于现有动画和特效资源设计的横版游戏招式。主线、开发者房间共用相同逻辑；弑君者的主页 B 键战斗同步生效。

| Boss | 新招式与变化 | 应对方式 |
| --- | --- | --- |
| 弑君者 | 后撤跳跃后蓄力，发射五枚瞄准锁定位置的扇形飞刀；远程招式轮换加入该招式，近身每三次攻击穿插一次。 | 0.75 秒预警中改变站位，剑气可拦截飞刀；出招后留出 0.48 秒反击时间。 |
| W | 连环爆破提前标出四个落点，半血后六个，逐个引爆并交替改变扫射方向；另有低空榴弹连射。 | 连环爆破中央蓝色空隙不在本招式的爆炸范围内；低空榴弹可跳跃或闪避，剑气仍能拦截。 |
| 霜星 | 蓄力扇形冰刃，首条生命五枚、第二条七枚；冰雨交替从左到右、从右到左、由外向内引爆。 | 冰刃方向在前摇时锁定，可通过换位避开；观察冰雨倒计时，避免沿固定方向躲避。 |
| 爱国者 | 第二条生命增加落矛阵：三个位置提前标记，矛依次从上方落下，命中造成两点伤害。 | 1.15 秒起的标记锁定后移出对应位置；矛之间有 180 的间距，施放后留出反击时间。 |

霜星对已冷却的技能轮流安排，避免冰环或黑冰一直挤掉其他招式。扇形冰刃之后会接一轮普通攻击，防止原来的冰刃齐射消失。每个新攻击在最终击败后均清理弹道、预警与伤害区域。

验证：`boss_variety_tests` 检查新招式实际伤害、预警、空隙、拦截、半血/重生变化、出招可达性及击败清理；`world_map_smoke --boss-variety-audit` 通过真实游戏更新和绘制流程输出各招式截图，并检查中文提示字形。

## 弑君者：赤影处刑（2026-10-04）

按用户确认的高速残影连斩方向，新增自制招式「赤影处刑」。这是本项目设计的技能，使用现有弑君者图集和程序绘制的刀光、残影、粒子；并非其他游戏技能的逐帧资源复刻。

- 战斗开始约 8 秒后，在下一次待机选择时优先施放，近身和远距离都能触发。后续从起手计时冷却 16 秒，半血后 12 秒。
- 三条斩击路线在起手时锁定，先闪现到第一刀起点，再进行 1.20 秒无伤准备；清掉前一招残留飞刀。每次只显示当前一条危险路线、躲避方向和剩余秒数，路线用源纹理标出刀锋 44 宽的范围。
- 前两次瞬斩各 0.30 秒，第三次 0.18 秒；后两刀先闪现到各自起点，再进行 0.75 秒无伤准备，不再于出刀瞬间换位。第一刀水平穿越，后两刀从两侧高位交错向下。单条路线跨越 480 距离；客户端刀光随前两段同步放慢，本体准备动作定格后才播放出刀。
- 三刀后重新读取玩家当前位置，闪现至玩家正上方，距地面至少 260、距玩家至少 220（受场地顶部限制）。此时锁定地面落点，终结预告 0.90 秒；红圈显示落地伤害半径 110，玩家移动后不会继续追踪。随后 0.24 秒垂直下斩，落地伤害窗口 0.16 秒，反击后摇 1.1 秒。
- 每段斩击最多命中一次，每次一点评定伤害；终结的下落刀锋与落地爆发共享一次命中。预告、换位及整段后摇关闭本体碰撞伤害。高速刀锋按每个外层更新帧内的所有移动段检测，避免穿透玩家。
- 演出包括红色角色残影、弧形刀光、蓄力环、落地扩散环与碎光，搭配现有蓄力/挥刀/技能冲击音效。残影尾迹独立淡出，不延长伤害。
- 主页 B、主线高架桥和开发者房间继续共用 `Boss` 控制器与 `Boss::Draw` 演出，原来的冲刺、飞刀与近身招式仍在。

验证：`boss_variety_tests` 增加 30/60/120 帧及 0.1 秒更新间隔的实伤、四次命中、锁定路线、可躲区域、预告、反击时间、眩晕、击败清理、落地范围与尾迹无伤害检查；`story_boss_tests` 覆盖 B/开发者房间同一控制器的终结状态；`world_map_smoke --crown-shadow-audit` 从真实主页进入开发者房间与 B 战斗并输出整段演出截图。

战斗显示调整：取消 Boss 技能名称横幅、角色上方技能名和血条下的招式播报；第二阶段提示只显示 Boss 名与阶段。保留攻击路线、危险范围、落点倒计时以及跳跃/闪避/修复等直接操作提示。技能逻辑、特效和音效不变。

## 弑君者特效改用客户端素材

根据用户要求，删除 `BladeRibbon` 曲线拼接刀光、自绘扩散椭圆、环绕短线粒子以及飞刀的几何十字；演出统一改由 `crown_client_fx.cpp` 播放原纹理。主页 B 的 `BossRenderer` 和主线/开发者房间的 `StoryBossRenderer` 共用相同播放逻辑。

- 三段斩击及空中下斩：使用弑君者/红的 `daoguang_09` 与 `daoguang_03`，原角色图集残影，以及源 `trail_08` 速度纹理。
- 闪现与消散：使用缄默德克萨斯的原 `smoke_26`，保留原尺寸及透明度曲线。
- 落地：使用原 `dilie_12` 地裂纹理、`trail_72` 分帧冲击、`star_64` 命中闪光、`smoke_26` 尘雾和 `star_54` 碎片；原 prefab 的 0.15 秒发射延迟对齐实际落地时刻。
- 攻击路线及落点标记：改用原 `trail_08`、`zhunxing_01` 与 `ray_06` 图片。没有恢复技能名称播报。
- 飞刀：复用项目现有的原剑形纹理，按碰撞体缩小显示，取消十字线拼接外观。

纹理保持源像素。源曲线按 60 Hz 采样；为适应明亮的横版背景，刀光调整曝光和播放速率。当前使用原素材编排新的自制招式，不宣称重现原 Unity 网格、着色器或完整原技能。

`tools/extract_crown_combat_fx.py` 可从客户端只读重新提取。`world_map_smoke --crown-shadow-audit` 检查 B/主线渲染器资源是否就绪并输出各阶段实机画面；`--crown-client-preview` 输出完整 5.5 秒的实际游戏绘制帧，用于查看运动中的效果。

反应窗口验证：30/60/120 帧下，按正常移动速度 320、延迟 0.25 秒后按提示方向走位，可以避开三刀及落地爆发；另检查闪现先于无伤准备、准备期间位置固定。半血普通背后闪现的准备时间由 0.20 延长到 0.55 秒，并锁定冲刺方向；普通攻击准备期关闭本体接触伤害，冲刺及空中斩击补充源纹理路线与倒计时。

其他 Boss 的投枪光痕和方向标记也改用原 `trail_08` 纹理；后续演出优先使用客户端原素材，避免再用线条、圆环等几何形状拼装刀光和冲击。
