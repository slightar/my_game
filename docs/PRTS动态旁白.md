# PRTS 阶段旁白

PRTS 保留头像、教程气泡、逐字显示和淡出，主要在战斗前后及地图探索时回应玩家。已移除最近十秒滚动统计和战斗中的自动打法、受伤、换弹、切换干员点评。

## 发言时机

| 阶段 | 行为 |
| --- | --- |
| 区域进入 | 导航开场；回访、首次进入未登记区域及系统空间使用不同回应 |
| 战斗开始 | 一条交战提示；同一区域后续增援波次不重复开场，也不重置战斗记录 |
| 战斗进行 | 正常保持安静，受伤、低生命、换弹、技能和切换不会自动弹出旁白；HUD 照常反馈战况 |
| 战斗结束 | 一条整场总结，将受伤/生命状态与主要打法合并；无伤、普通和快速清场也有不同措辞 |
| 行动失败 | 作为战斗结束立即给出一次失败反馈，不在后续帧反复播放 |
| 探索地图 | 对主动调查、持续折返、封闭通路尝试和进入支路给出回应；多次偏离改变本次行动中的态度 |
| 偶尔闲谈 | 时间和台词随机，在当前对话结束后出现；每区域探索最多两次，战斗途中最多一次 |

随机探索闲谈首个候选时机在进入/清场后 30–50 秒；随机战斗旁白首个候选时机在交战开始后 45–70 秒。短战斗通常不会有途中旁白。随机候选依据实际停留、折返、登高、生命状态等上下文选择，未满足的情况不会被随机捏造。普通发言至少相隔 14 秒，主动读取记录、战斗边界和失败使用较高优先级。结算区域不插入随机闲谈。

## 整场战斗记录

记录从第一次交战/敌方增援开始，到本区域清场或行动失败结束，跨越同一区域的所有增援波次。统计成功完成的远程攻击、近战、技能、闪避、干员交接、有效受伤，以及整场交战时间；不遗忘十秒以前的行为。打法只在战后选择一次：技能频繁、机动频繁、近战主导、远程主导或多次干员交接。证据不足时仅给出战斗结果。

战后总结在该帧生命状态更新后生成，避免遗漏清场同时发生的伤害。每次战斗仅有一个总结气泡，不依次排播多个点评。切换到新场景清理本区域记录与待播消息；本次行动的台词轮换和偏离态度跨场景保留。重新行动重置行为记忆，不改存档、地图路线、敌人或装备效果。

## 组件与边界

`src/prts_narrator.h/.cpp` 为独立本地策略，不依赖键盘、绘制、音频、敌人或存档，也不调用在线模型。玩家组件只汇报实际完成的动作，游戏层适配事件，显示层读取当前消息、时间、危险色、频道与淡出程度。随机源在行动开始时初始化；测试可注入固定种子。

隐藏出口附近不自动发言，不透露尚未发现的目的地；回应来自主动调查或实际进入。系统空间使用校验异常的表达，不预告协议失效。

## 验证

- `prts_narrator_tests`：一次战前提示、跨波次统计、整场打法总结、战斗中不自动点评、战后结果去重、随机时间与次数上限、探索回应、失败去重及场景边界。
- `world_map_smoke.exe --prts-audit`：实际开枪与受伤期间保持安静，战后读取真实动作与生命状态，附近不泄露隐藏入口，进入后回应，中文字符和气泡截图。
- 常规地图回归验证原有通路、调查、红门出怪、清场通行和回访。
