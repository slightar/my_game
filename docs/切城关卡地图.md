# 切尔诺伯格关卡地图

依据用户提供的城区横截面流程图，实现 20 个区域、24 条连接。玩家入口沿用原有关卡选择界面的客户端素材、顶部分类、路线节点、右侧简报和“开始行动”按钮；节点内容替换为切城的 20 个区域。点击“开始行动”进入所选区域。

完整横截面大地图作为设计原型保留在项目中，不向玩家开放。

## 分层与路线

| 层级 | 区域 |
| --- | --- |
| 高架层 +2 | 停摆钟楼、高架桥、通讯塔上层 |
| 建筑上层 +1 | 城市核心、任务结算 |
| 地表 0 | 灰雪街区、高架入口、废弃通讯站、冰封居住区、燃烧街区 |
| 地下 -1 | 地下诊疗所、旧车站、维护井、热能管线、工业区关口 |
| 设施深层 -2 | 零号病房、冰下避难所、PRTS 数据根系 |
| 系统空间 | PRTS 核心、魔王王座 |

青色主线：地下诊疗所 → 灰雪街区 → 高架入口 → 高架桥（弑君者）→ 通讯塔上层（W）→ 废弃通讯站 → 冰封居住区（霜星）→ 热能管线 → 工业区关口（爱国者）→ 燃烧街区 → 城市核心（塔露拉）→ 任务结算。

金色探索支路：

- 灰雪街区 → 停摆钟楼 → 高架桥。
- 旧车站 → 高架入口；旧车站 → 零号病房 → 地下诊疗所。
- 旧车站 → 维护井；废弃通讯站 → 维护井 → 热能管线。
- 热能管线 → 冰下避难所 → PRTS 数据根系。

粉色终章连接：城市核心 → PRTS 数据根系 → PRTS 核心 → 魔王王座。

地图箭头保持流程图方向。空白区域中的普通通道暂时允许双向回访，所以可以从高架入口进入旧车站；粉色连接保持单向。共 45 个可通行方向。系统空间与物理楼层分开表示，王座不作为切城内的一间建筑房间。

序章“诊疗所 → 魔王王座 → 茧笼断线 → 诊疗所重生”只作为地图顶部说明，不添加物理捷径，也不执行序章演出。

## 当前可操作范围

- 关卡选择显示 12 个主线路径节点，初始可从地下诊疗所出发。已探索区域可重进，已探索主线区域的下一个主线节点可进入。
- 停摆钟楼、旧车站、零号病房、维护井、冰下避难所、PRTS 数据根系、PRTS 核心、魔王王座，在实际进入前不显示按钮、名称和连接线，也不能通过键盘导航或确认按钮进入。
- 场景中靠近尚未发现的支路时只显示“调查通道”；按 F 实际进入后才保存发现记录。主线相邻、仅选中节点、旧剧情解锁或调试解锁均不会发现隐藏区域。
- 区域使用现有角色模型及移动、跳跃、闪避和切换干员操作。到出口按 F 切换，Tab、M、Esc 返回原样式的关卡选择，并定位当前区域。
- 发现记录和当前区域保存到原存档中的 `visitedRegions` 和 `selectedRegion`，兼容没有这些字段的旧版存档，不改写旧剧情的完成状态、奖励和装备。重置进度会一并清除发现记录。
- Boss 战、机关、藏品、额外开路条件和结局演出仍未实现。进入或发现区域不会自动领取原剧情任务奖励。
