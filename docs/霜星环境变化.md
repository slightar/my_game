# 霜星战环境变化

霜星区域复用已有 `ice_scale_v3.png` 白天居民街景，代替一进场就是冰封夜景的 `ice_boss_v1.png`。屋顶和路边保留素材本身的冬季积雪；触发战斗前没有动态降雪、寒雾或额外冷色处理。街景结构和战斗场地宽度不随演出改变。

触发战斗后约 3 秒内逐渐压低背景暖色、降低饱和度并转向冷蓝。冷色处理只作用于背景图层，角色、攻击预警和界面保持原色。地面按现有街景素材重新对齐。

雪花复用客户端 `flipbook_51`，分为背景 110 片和前景 28 片，不同大小、下落速度、摆动与视差形成纵深。背景雪花及 `xue_01` 贴地寒雾位于角色和攻击预警之后，前景雪花较稀疏，接近地面时透明淡出。没有新绘制雪花素材。

第一阶段天气强度上升至 0.72，复活期间保持，第二阶段继续上升到 1，增加雪量可见度和寒雾浓度。最终击败后约 6 秒恢复正常，切换地区或重试重置天气；主线与开发者房间共用逻辑。天气没有碰撞或伤害效果。

`winter_boss_tests` 检查接战前无雪、逐渐变冷、复活连续、第二阶段增强、击败消散和地区重置。`world_map_smoke --frost-weather-audit` 通过真实游戏更新路径检查着色器编译并导出 `frost-weather-before/arrival/phase1/phase2/cleared.png` 实机画面。
