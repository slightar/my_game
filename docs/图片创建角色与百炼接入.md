# 图片创建角色与百炼接入

## 使用

1. 启动 `cmake-build-debug/my_game.exe`。主菜单按 **F4**，或进入角色编队后点击右上角的“图片创建角色”。
2. 工坊优先读取 `DASHSCOPE_API_KEY` 环境变量，否则读取可执行文件旁的 `save/character_api.local.json` 中的 `apiKey`。此本机私有文件已被 Git 忽略，不属于角色数据或普通生成设置。当前开发机已配置用户提供的密钥，打开工坊会自动填入并遮罩显示。界面临时修改的密钥仅保留在本次进程中。
3. 默认 API Host 为北京公共域名 `https://dashscope.aliyuncs.com`，默认模型为 `qwen-image-2.0`。模型和地域必须已在账户开通，密钥必须具有相应权限。
   - 新加坡公共域名：`https://dashscope-intl.aliyuncs.com`。
   - 业务空间专属域名：从百炼控制台复制，如 `https://业务空间ID.cn-beijing.maas.aliyuncs.com`。粘贴 SDK 中带 `/compatible-mode/v1` 的完整地址会自动提取 Host。不要根据密钥前缀推断地域或权限。
4. 点击“选择参考图”，或将 PNG、JPG/JPEG、BMP 拖入工坊。推荐完整人物图。可以填写角色名和补充人物特征。
5. 点击“生成小人”。**这一操作会将参考图上传百炼，并可能产生账户费用。** 默认开启“智能分析”：先由 `qwen3.8-max` 识别外观、名称与武器类型，再将外观信息加入图像编辑请求，最后下载小人。未手动指定时自动应用名称和近战／射击／法术模板；手动填写的名称和选定的模板优先。可关闭智能分析直接生成。每次只提交一次图片生成；仅下载环节可重试两次。
6. 完成后检查小人外观、透明区域及动作。近战自动套用挥斩模板，射击套用后坐力模板，法术套用施放模板；工坊可预览待机、跑步、攻击、跳跃、下落、落地、闪避、受击和倒地，也可翻转朝向。去绿幕误伤人物时可关闭，背景不干净时重新生成。
7. 点击“保存并返回编队”，将新角色编入出战栏并保存编队。角色和素材会复制到可执行文件旁的 `characters/`，重新启动仍可选择。
8. 编队中选中本地角色，点击“删除角色”或按 Delete，再确认。仅本地创建／导入角色可删除；出战栏按稳定 ID 保持其他角色，删除的栏位回退内置干员。角色定义移入 `characters/.trash/`，素材保留，可将定义文件移回 `characters/` 并按 F5 恢复。内置干员和随游戏附带的示例不能从此入口删除。

密钥输入使用遮罩，支持粘贴；Tab 切换输入框，Ctrl+V 粘贴，Ctrl+A 清空当前字段。中文名称和描述支持输入法，也可粘贴。

无需 API 也能试验：“使用原图”直接生成本地角色预览。原图建议使用透明背景的完整小人，否则背景也会进入游戏。

## 行为与限制

- 当前生成的是**单张小人图**，使用整体姿态关键帧和挥斩轨迹／射击闪光／法术环表现攻击；尚未自动生成身体分件或逐帧动画，不等同于独立迈腿、挥臂。视觉效果不改变伤害、碰撞框和攻击间隔。
- 按接口规范发送单条 user 消息，content 包含 PNG Base64 参考图和编辑指令。生成结果中的 HTTPS 图片 URL 立即下载到内存，**下载请求不携带 API Key**。
- 参考图载入后等比缩小到最长边 1536，编码后的 PNG 不超过 10 MiB；生成响应和图片下载均限制大小。只接受尺寸 16–4096 的 PNG 生成结果，解码前先检查 PNG 头和尺寸。
- 不假定模型能够输出真实透明通道：提示词要求纯绿色背景，在本地仅去除与边界连通的绿色区域，然后裁切并留统一透明边距。这个方法可能残留绿边或误伤与背景相连的绿色衣服，也不会保证每张结果都完整；提供原图预览、开关和重新生成供检查。
- 角色玩法来自三个本地模板。图片分析只推荐基础战斗类型，不编造专属技能；默认带恢复和剑雨／散射技能，继续使用已有配置验证与战斗执行。
- 网络和下载在后台工作，纹理与图片处理在游戏主线程。返回菜单不会取消任务，重新打开工坊可查看结果。
- “取消等待”使迟到结果失效，不会保存或导入。已提交的服务端推理未必停止，仍可能计费；网络连接结束前不重复提交新请求。退出游戏无需等待云端返回。
- 普通生成设置保存 Host、图像模型、补充描述、智能开关和分析模型，位置为 `save/character_generation.json`，不含密钥。本地草稿位于 `save/character-drafts/`；最终保存通过现有 `LocalCharacterRepository::Import` 完成，导入失败不会提交不完整角色。
- 智能分析返回结构不合法或模型不可用时，降级为原始图像描述并明确提示；鉴权失败停止请求。界面显示识别、生成、下载三个阶段。图像栏拒绝聊天模型；当前图像请求支持 `qwen-image-2.0`、`qwen-image-edit` 系列，其他协议需单独接入。
- 命中反馈覆盖自定义与内置角色：普通命中约 1 像素／65ms 轻震，击杀约 4 像素／180ms 震动，随时间衰减；不暂停模拟。HUD 不随震动移动；同位置密集命中合并，击杀升级不被合并吞掉。Boss 复活换阶段不算击杀。命中与普通斩击播放现有 65 帧透明图集，替代程序绘制光圈／线段火花；自定义远程攻击提示也播放帧动画。伤害与命中判断沿用原系统。
- 401/403 显示鉴权与权限提示，429 显示限流提示；服务错误不打印原始响应、签名 URL 或密钥。当前 HTTP 传输使用 Windows WinHTTP，保留系统证书校验，不将鉴权转发到重定向地址。

## 代码与验证

- `src/character_generation.*`：设置、请求协议、角色模板、后台任务与取消结果隔离。
- `src/character_http.cpp`：有大小上限与超时的 HTTPS 传输。
- `src/character_sprite_processing.cpp`：PNG 检查、连通背景去除和透明裁切。
- `src/character_creator*`：工坊交互、原生选图、输入法、动作预览和持久化。
- `src/character_motion_templates.*`：独立的动作模板数据与采样，包含身体位移、缩放、倾斜及头／手臂关节角度。预览与实战共用；攻击叠加到移动和空中姿态，受击／闪避／倒地中断攻击演出。
- `src/combat_feedback.h`：独立的命中／击杀表现、实时寿命、帧动画和有上限的镜头偏移。
- `tests/character_generation_tests.cpp`：模拟官方响应，检查协议、密钥隔离、取消、图片处理与角色持久化；不调用计费接口。
- `tests/character_creator_smoke.cpp`：隐藏窗口检查空态、预览、跑步、镜像攻击、错误提示、按钮保存和重新打开，截图写入 `cmake-build-debug/character-qa/creator-*.png`。
- `tests/character_motion_render_checks.h`：输出三套攻击时间序列和单图／分件九种动作对照图 `motion-template-*.png`。

### 模板配置与分件扩展

角色 JSON 的 `assets.motionTemplate` 支持 `auto`、`melee`、`ranged`、`caster`。工坊新保存的角色会写入所选模板；旧角色没有此字段时默认 `auto`，按原有攻击类型和伤害属性选择模板，无需重新生成图片。可通过 JSON 将视觉模板与战斗配置分开设置。

需要独立手脚运动时，使用 `examples/rig_character.json` 的格式准备 `torso`、`head`、`armFront`、`armBack`、`legFront`、`legBack`，以及可选的 `weapon` 透明分件；`weapon` 绑定前臂。设置 `animationMode` 为 `rig`（或保留 `auto`），配置关节坐标和枢轴，同一套动作模板就会驱动这些部件。当前不把整图按矩形强行切成身体部件，需另行制作或生成分件素材。

已有逐帧角色的有效动画行保持优先；缺少攻击行时使用模板补足。可用 `motionStrength` 调整模板幅度（0–2）。

```powershell
cmake --build cmake-build-debug
ctest --test-dir cmake-build-debug --output-on-failure
.\cmake-build-debug\character_creator_smoke.exe
```

接口依据：[千问图像编辑 API](https://help.aliyun.com/zh/model-studio/qwen-image-edit-api)、[视觉理解](https://help.aliyun.com/zh/model-studio/vision)。当前开发机的专属地址与密钥通过模型列表接口得到 HTTP 200；此次未提交真实计费推理，图片生成与智能分析通过模拟官方响应验证，不能据此保证所有模型的账户权限。


### 免费额度用尽与鉴权错误

HTTP 403 不一定是密钥失效。读取百炼的结构化错误码后分别提示免费额度、欠费、服务未开通和访问权限问题，并标明失败发生在图片分析还是图片生成阶段；不显示服务器原始消息，不自动重复付费生成请求。

`AllocationQuota.FreeTierOnly` 表示目标模型的免费额度已用尽或到期且开启“免费额度用完即停”。如需继续按量付费，在对应地域的百炼控制台免费额度页面找到该模型，关闭该开关并检查账户余额；这项设置由用户决定。无需因为此错误更换 API Key。

官方说明：https://help.aliyun.com/zh/model-studio/new-free-quota
错误码说明：https://help.aliyun.com/zh/model-studio/error-code
