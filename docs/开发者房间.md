# 开发者房间

在主页点击「开发者房间 / F12」，或按 F12 进入。沿用当前编队，使用已有中继设备廊场景，初始没有敌人，默认开启无敌。召唤霜星或爱国者时自动切换各自专场背景与原战斗音乐，第一条生命耗尽后继续第二阶段，详见 [霜星与爱国者](霜星与爱国者.md)。

敌人列表包含现有 31 类小怪和已实现的弑君者、W、霜星、爱国者，使用与主线相同的客户端模型、攻击、技能及判定。可以筛选全部／小怪／领袖；小怪与领袖可同场测试。生成一名领袖会替换当前领袖，并清除被替换领袖的全部攻击和持续危险区域。

| 操作 | 按钮或快捷键 |
| --- | --- |
| 选择敌人 | 点击列表、↑↓、列表内滚轮 |
| 分类／翻页 | Tab／PageUp、PageDown 或左右按钮 |
| 数量 | +/-，每批 1～20；领袖固定 1 名 |
| 生成 | Enter 或生成按钮 |
| 位置 | 玩家右侧、左侧，或 Shift + 点击场景标记位置 |
| 冻结／运行敌人 | F4 |
| 敌人单步 | 冻结时按 F5，每次推进 1/60 秒 |
| 无敌开关 | F9 |
| 恢复编队 | F3，恢复两名角色的生命、弹药、技能状态与冷却 |
| 清场 | Delete，清除全部敌人、敌方攻击与玩家弹幕 |
| 显示／隐藏面板 | F1 |
| 返回主页 | Esc |

角色移动、跳跃、攻击、技能仍使用当前设置中的按键，1/2 切换角色。冻结仅影响敌人，角色仍可行动、射击及测试命中；角色全部阵亡后仍能恢复、生成或清场。

面板提供 0.5 / 1 / 2 倍测试速度，以及原始、进阶、高压三档参数。参数只影响新生成的单位，已生成敌人保持生成时的生命、移动和攻击参数。原始参数为 1 倍；进阶和高压分别复用自适应系统能力值 0.6、1.0 的参数映射。

场上最多 64 个小怪及 1 名领袖。超过上限时整批取消生成，清场后可继续。批量生成按 60 像素间距排列，场景边缘会限制位置，飞行敌人自动在空中生成。

测试场拥有独立的 EnemySystem 与 StoryBoss，不记录区域发现、剧情进度、装备收益，也不采集自适应难度数据。退出不写入主线存档；再次进入恢复空房间和默认控制设置。

实现分为 `developer_room.cpp`（测试场状态与生成）、`developer_room_view.cpp`（界面与输入）、`developer_room_game.cpp`（角色、战斗与场景接入）。扩充小怪数据表后会自动出现在目录；领袖目录使用 StoryBossKind 与统一的名称、ID 和场景映射。

验证：`developer_room_tests` 覆盖目录、筛选、生成上限、混合生成、冻结与单步、参数隔离和重置。`world_map_smoke --developer-room-audit` 从实际主页入口验证鼠标释放与拖出取消、全部客户端模型、实际攻击命中、无敌开关、阵亡恢复、存档及难度隔离，并输出截图。运行集成检查时请使用单独的测试目录，隔离测试存档。
