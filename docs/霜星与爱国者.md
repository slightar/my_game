# 霜星与爱国者：双阶段专场

正常行动先经过原来的落雪庭院／货运支线小怪区域，再进入冰封居住区（霜星）／工业区关口（爱国者）。前进到区域宽度的 36% 触发遭遇。第一条生命耗尽后进入重生，出口继续锁闭；必须击败第二条生命才解除封锁。回访已清理区域不会复活 Boss，重新行动或全队倒下重试则恢复第一阶段。

开发者房间按 F12 进入，切到「领袖」分类后选择霜星或爱国者，Enter 生成。自动切换专场背景与战斗音乐，使用相同战斗逻辑。F9 关闭默认无敌可检查寒冷、冻结与实际伤害；F4 冻结敌人、F5 单步、F3 恢复编队、Delete 清场。独立测试不写入主线存档，也不训练自适应难度。

## 霜星 · 冬痕

使用第六章原模型 `enemy_1510_frstar2`，每条生命基准 140。冰封居住区专场是冰雪覆盖的供热走廊，窗外有切城、黑冰和极光。雪粒与角色处于不同景深，镜头兼顾玩家和 Boss，避免右下角技能栏遮挡交战目标。

| 招式 | 第一阶段 | 第二阶段 |
| --- | --- | --- |
| 冰霜攻击／齐射 | 0.8 秒蓄力后向预先瞄准的位置发射冰刃；每三次攻击改为 0.98 秒蓄力的三路齐射。冰刃造成 1 点伤害与寒冷，剑气可击毁 | 弹速从 360 提升至 440，后摇从 1.55 秒缩短至 1.25 秒；移动速度从 150 提升至 195 |
| 冰环 | 1.15 秒预警，半径 250 的地面冰环；造成寒冷，冻结目标伤害翻倍 | 半径扩大为 390，基础冷却从 6.8 秒缩短至 5.2 秒 |
| 冰雨 | 在锁定位置周围标记 3 个落点，施法后各落点依次倒计时并降下冰刃；命中造成 1 点伤害与寒冷，可通过横向移动离开落点 | 增至 5 个落点，基础冷却从 11.5 秒缩短至 8.8 秒 |
| 黑冰封印 | 标记 2 块地板，2.4 秒后封住地块并使其失去支撑；角色踩空后受 2 点伤害，返回最近的安全地面。封印地板可攻击 4 次修复，或等待 18 秒自然解冻 | 标记 3 块地板，基础冷却从 11 秒缩短至 8 秒 |
| 源石冰晶 | 尚未启用 | 战场两侧出现原特效冰晶，每 8 秒发出低空寒潮；第三次两侧同时夹击，可跳跃躲避 |
| 重生 | 第一条生命耗尽后 4 秒重生，回满生命；原技能动作、冰霜剪影、冰环与阶段标题共同表现 | 重生后 3 秒保护期，冰环与冰晶仍有各自预警 |

寒冷持续 4 秒，期间再次受到有效寒冷攻击会冻结 2 秒。受击无敌期间不会重复叠加寒冷；开发者无敌开启时也不会冻结。跳跃可避开冰环和低空寒潮，也可跨越被封的地板。封印本身没有冰晶接触伤害，也不附加寒冷；踩空才会受伤。射击、剑气等攻击可击碎封印，修复地面；封印也会自然解冻，重生时现存封印不会被立即清除。重叠位置不会重复生成，最多保留 6 块。玩家连续站桩超过 2.5 秒会提前压低下一次冰雨的冷却，迫使玩家移动；霜星两个阶段都免疫眩晕。

## 爱国者

使用第七章原模型 `enemy_1506_patrt`，每条生命基准 180。工业区关口专场为残阳下的破损铸造厂，保留连续地面、断墙、吊机与红色旗帜，第二阶段加入原客户端献祭和投枪效果。

| 招式 | 行军 | 毁灭 |
| --- | --- | --- |
| 护甲 | 受到的物理／法术伤害分别为原值的 35%／65% | 分别为 70%／80%，使用 `Idle_2 / Move_2 / Attack_2` 原动作 |
| 近战 | 0.9 秒前摇，1.6 秒内四次攻击，间隔 0.36 秒；每次使用独立命中区域 | 0.75 秒前摇，改为范围更大的单次重击 |
| 移动 | 追击速度基准 98 | 追击速度基准 145 |
| 盾阵推进 | 0.9 秒预警后架盾推进约 3.5 秒，并释放有预警的地面脉冲；正面攻击伤害降至 25%，背击不减伤，正面累计攻击可击破盾阵 | 盾耐久提高，持续约 3.1 秒；与第二阶段持续献祭形成复合站位压力 |
| 冲锋／地面波 | 距离 260～760 时使用，1 秒预警后向锁定的位置冲锋；可跳跃或闪避，命中造成 1 点伤害。冲锋结束后沿前方发出可跳跃躲避的地面波 | 预警 0.75 秒、冲锋更快且命中造成 2 点伤害；冲锋结束时地面波同时向两侧扩散 |
| 生命献祭 | 倒地重生期间开始释放 | 每 0.8 秒脉冲一次，半径 205，0.16 秒预警；远离或跳跃可躲开 |
| 投枪 | 尚未启用 | 距离超过 190 时使用，2 秒前摇；前 1.05 秒追踪，之后红色准星锁死。原投枪纹理真实飞行并造成 2 点伤害，落地后产生小范围冲击 |
| 重生 | 6 秒，依次播放 `revive_1 / revive_2 / revive_3`，回满生命 | 重生后 2.5 秒保护期，免疫眩晕；护甲外观与攻击动作切换为毁灭姿态 |

这些数值是横版动作适配：原作较长的复活与无敌时长被缩短；封印地块在横版地图中成为失去支撑的地面；投枪的远端高台目标改为当前角色提前锁定的位置；献祭改为可跳跃规避的地面脉冲。爱国者受到持续攻击后会提前准备盾阵，正面可集中火力破盾，背后攻击则保持完整伤害。冰雨、双向寒潮、盾阵推进与冲锋地面波是围绕原作能力设计的横版追加招式，不是原作招式的逐项复刻。主线当前两场均为单 Boss 对决，未加入爱国者对其他敌人的指挥增益。技能构成参考 [霜星，“冬痕”](https://prts.wiki/w/%E9%9C%9C%E6%98%9F%EF%BC%8C%E2%80%9C%E5%86%AC%E7%97%95%E2%80%9D) 与 [爱国者](https://prts.wiki/w/%E7%88%B1%E5%9B%BD%E8%80%85)。

自适应系统在入场时冻结本场生命、移动、弹速和技能冷却倍率，跨两阶段保持一致，整场结束才计算下一场难度。重生保护、技能预警和投枪锁定时间保持固定。

## 原始模型、特效与音频

模型来自 `refs/arts/enm_art_16.ab`，所有动作以相同脚底锚点烘焙。霜星现从原 Spine 骨骼以每秒 30 帧重新采样，7 段动作共 796 帧，按透明边界裁切后存于 `frostnova_smooth.png/json`；爱国者仍使用每段 20 帧的 512×512 图集。运行时霜星待机高度 115，爱国者 175，统一等比缩放。模型 ID、对象 ID、原骨骼 SHA-256、动画时长、锚点都记录于 `assets/enemies/bosses/manifest.json`。

霜星施法动作映射：冰环播放 `Skill_3` 的下蹲释放动作，掀地板播放 `Skill_1` 的施法动作；两种贴图特效与判定仍各自绑定原技能。

技能美术直接使用客户端 `battle/prefabs/effects/frstar2.ab`、`patrt.ab`、`crowns.ab`、`cqbw.ab` 及其依赖纹理，原 PNG 透明度与像素保留，共 66 张去重纹理。`effects/manifest.json` 保留来源、纹理 SHA-256 与原材质参数。W 的地雷、C4、榴弹与弑君者斩击也已换用客户端纹理。

| 表现 | 原客户端素材 |
| --- | --- |
| 冰环 | 客户端 `frstar2_attack_02_start` 的 `huan / xian / sanjiao / baoshan` 四层：`frstar_01`、`trail_08`、`star_10`、`star_02`。按原粒子的短促爆发作横版投影，不再叠加无关的 `water_05`、`haak_03` |
| 封印地板 | 原 `frstar2_skill_03_range` 使用的 `dilie_08`、`water_05` 地裂材质；预警使用 `trail_08` |
| 冰雨 | `water_05`、`xue_01` 预警；`frstar_07 / 09` 落地 |
| 第二阶段冰晶／寒潮 | `frstar_05`、`frstar_07` |
| 重生冰霜剪影 | `frstar_02 / 03`、`trail_08` 上升冰屑；结束时释放一次冰环 |
| 冰刃 | `flipbook_06`、`trail_08` |
| 爱国者重生／献祭 | `patrt_01 / 02 / 03 / 12 / 13`、`flow_34`；结束冲击使用 `haak_03` |
| 斩击／投枪／命中 | `patrt_05 / 07 / 16 / 17`；落地冲击使用 `haak_03`、`patrt_03`、`star_55`，不再把施法的人形剪影当作爆炸 |
| 盾阵／地面波 | `patrt_06 / 12`、`patrt_03 / 07` |
| 投枪准星 | `zhunxing_01` |
| W 地雷／C4／榴弹 | `cqbw_04 / 05 / 06`、`C4_02`、`cqbw_01` |
| 弑君者斩击 | `daoguang_09` |

2026-10-04 特效合成修订：冰环的黑色主体采用透明混合，光芒单独叠加，主体按导出粒子记录中的 0.45 秒寿命扩散消退。冰环和近战刀光放在角色前层；弑君者刀光仅在实际出刀时播放，保留原银白色。W 的骷髅保持正常比例，地面预警改用 `water_20 / trail_08`，爆炸分为闪光、扩散和余光，并去掉误用的枪械剪影 `cqbw_02`。重生按蓄能、释放分段，爱国者不再循环播放霜星冰环。资源完整性按 Boss 分别检查，避免其他 Boss 的缺图影响当前 Boss。

当前游戏用 raylib 2D 合成这些原素材，并以同一战斗状态驱动特效与判定；没有运行 Unity 的原粒子、网格和着色器，因此投影、节奏和层次是本项目的 2D 适配，并非完整复刻原引擎的粒子流程。封印地板使用客户端地裂纹理，不再竖起可接触的冰晶。地面倒计时和耐久提示是额外的玩法 UI。

原客户端音乐为 `m_bat_frostnova_loop`、`m_bat_frostnovaevolution_loop`、`m_bat_patriot_loop`。霜星重生完成后切换第二首；爱国者沿用同一战斗曲。霜星冰环与黑冰音效使用 `e_aoe_frostnovaice_h1 / h2`。音乐从原 PCM 转码为 Vorbis，技能音效保留 PCM；具体包路径、时长与采样指纹位于 `audio/sources.json`。离场停止音乐，敌人冻结时暂停播放，沿用当前音量设置。

## 模块与复现

- `winter_boss.cpp`：两名 Boss 的状态、复活、攻击与伤害，仅依赖战斗数据。
- `winter_boss_renderer.cpp`：按状态播放原模型动作。
- `boss_client_fx.cpp`：客户端纹理合成与阶段字幕。
- `boss_audio.cpp`：原战斗音乐与霜星技能音效。
- `world_preview.cpp / developer_room_game.cpp`：主线和独立测试场接入，原有关卡选择界面保留。

提取工具 `extract_winter_models.py --client ... --output output/winter-bosses/models --runtime ...` 只读客户端；随后执行 `bake_enemy_sheets.py --input output/winter-bosses/models --output output/winter-bosses/sheets --page tools/bake_winter_bosses.html`、`bake_enemy_sheets.py --input output/winter-bosses/models --output output/winter-bosses/smooth --page tools/bake_frostnova_smooth.html` 与 `install_winter_bosses.py`。特效工具为 `extract_winter_effects.py --client ... --output ...`，音频工具为 `extract_winter_audio.py --client ... --output ... --ffmpeg ...`。提取及烘焙中间文件在忽略的 `output/` 内，运行游戏无需安装这些工具。

`winter_boss_tests` 验证两条生命、重生保护、护甲差异、眩晕免疫、冰环扩张与跳跃、冰雨落点及寒冷、2.4 秒封印预警、射击修复与自然解冻、三路冰刃齐射、两侧夹击寒潮、四连击、盾阵正背面伤害差异与连续受击触发、冲锋移动与地面波、献祭、投枪锁定和命中、最终清理与回访。`world_map_smoke --winter-boss-audit` 从真实游戏更新路径验证主线触发、实枪伤害、两个阶段的出口、音乐切换、重试、开发者房间各技能画面、有效寒冷叠加冻结，以及存档和难度隔离。截图及日志在 `output/winter-bosses/qa/winter/`；集成测试使用独立存档目录。

自动集成测试在内存中将主音量固定为 0，进入菜单及房间后保持静音；音频加载与触发仍可验证，不会改写玩家的音量设置。

霜星场景已改为同一条白天街景在接战后逐渐变冷并飘雪，取代直接显示冰封夜景；详见 [霜星环境变化](霜星环境变化.md)。原夜景素材保留，当前战斗使用既有 `ice_scale_v3.png`。
